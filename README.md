# Мой бюджет
**«Мой бюджет»** - это веб-приложение, которое помогает следить за личными финансами, планировать расходы и лучше понимать свои денежные привычки.

## Цель проекта
Приложение позволит:
- Не теряться в повседневных расходах.
- Видеть, сколько денег приходит и уходит.
- Планировать расходы на неделю и месяц.
- Следить за тем, чтобы не выходить за рамки бюджета.
- Откладывать деньги на приятные покупки и важные цели.
- Лучше понимать, на что уходит большая часть денег.

## Технический стек
- HTML
- Tailwind
- JavaScript
- LocalStorage
- Chart.js

## Основной функционал

### 1. Главная страница
Общая информация о финансовом состоянии пользователя:
- Текущий баланс.
- Доходы за текущий месяц.
- Расходы за текущий месяц.
- Остаток бюджета на текущую неделю.
- Остаток бюджета на текущий месяц.
- Последние финансовые операции.
- Цели накоплений и прогресс их достижения.

### 2. Операции
Управление доходами и расходами:
- Добавление новых операций.
- Редактирование существующих записей.
- Удаление операций.
- Выбор типа операции: доходы или расходы.
- Указание суммы, даты, категории и комментария.
- Поиск и фильтрация операций.
- Сортировка по дате и сумме.

### 3. Бюджет
Планирование повседневных расходов:
- Установка общего лимита расходов на неделю или месяц.
- Создание лимитов для отдельных категорий расходов с выбором периода.
- Просмотр потраченной и оставшейся суммы по каждому лимиту.
- Визуальное отображение использования бюджета.
- Предупреждения о приближении к установленным лимитам.

### 4. Аналитика
Наглядная информация о финансовых привычках:
- Просмотр общей суммы доходов и расходов за выбранный период.
- Распределение расходов по категориям.
- Сравнение доходов и расходов за разные периоды.
- Определение наиболее затратных категорий.
- Графики изменения доходов и расходов во времени.

### 5. Накопления
Планирование личных целей:
- Создание собственных целей.
- Установка желаемой суммы.
- Учет уже накопленных денег.
- Отображение прогресса.
- Указание предполагаемой даты достижения цели.
